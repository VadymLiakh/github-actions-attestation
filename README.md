# GitHub Actions Attestation Project

Цей проєкт демонструє використання GitHub Actions для автоматизації тестування, перевірки якості коду та збірки Python-додатку.

## Мета роботи

Основна мета — закріпити навички роботи з GitHub та GitHub Actions (CI/CD), а також навчитися автоматизувати перевірку коду.

## Опис проєкту

У проєкті реалізовано простий модуль калькулятора з базовими операціями:
- додавання
- віднімання
- множення
- ділення
- обчислення середнього значення

Для перевірки роботи функцій написані unit та integration тести.

## Реалізовані завдання

### 1. Автоматичне тестування (Pytest)
Після кожного push автоматично запускаються тести, які перевіряють правильність роботи функцій.

### 2. Перевірка стилю коду (Linting)
Використовується flake8 для перевірки відповідності коду стандартам.

### 3. Мультиверсійне тестування
Проєкт тестується на кількох версіях Python:
- 3.10
- 3.11
- 3.12

### 4. Docker
Автоматично збирається Docker-образ і перевіряється запуск контейнера.

### 5. HTML-звіт
Після виконання тестів генерується HTML-звіт за допомогою pytest-html.

## Як працює GitHub Actions

Workflow запускається автоматично при:
- push у гілку main
- створенні pull request

Виконуються такі кроки:
1. Встановлення Python
2. Встановлення залежностей
3. Запуск тестів
4. Перевірка стилю коду
5. Збірка Docker-контейнера
6. Генерація HTML-звіту

## Запуск проєкту локально

### Встановлення залежностей
```
pip install -r requirements.txt
```

### Запуск тестів
```
pytest tests/
```

### Перевірка стилю коду
```
flake8 app tests --max-line-length=88
```

### Генерація HTML-звіту
```
pytest tests/ --html=report.html --self-contained-html
```

## Docker

### Збірка образу
```
docker build -t calculator-app .
```

### Запуск контейнера
```
docker run --rm calculator-app
```

## Висновок

У цьому проєкті реалізовано повний цикл CI:
- автоматичне тестування
- перевірка якості коду
- підтримка різних версій Python
- контейнеризація
- генерація звітів

Це дозволяє забезпечити стабільність, надійність і якість програмного забезпечення.
